# WigglyTester

Release builds of WigglyTester, the Dalamud plugin that gives invited testers access to WigglyMuffin test plugins. This repository holds release assets only.

Install: add `https://raw.githubusercontent.com/WigglyCorp/DalamudPlugins/main/testers.json` under Dalamud Settings -> Experimental -> Custom Plugin Repositories, then install WigglyTester and redeem the key you were given with `/wtester`.
